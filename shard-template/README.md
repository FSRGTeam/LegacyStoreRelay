# LegacyStoreDC<N>

Шард каталога Legacy Store: карточки приложений, иконки и собранный `catalog.tsv`.
Список шардов и склеенный каталог живут в LegacyStoreRelay.

```
apps/<bundleId>.json   карточка: автор, ссылка, sha256, номер заявки
icons/<bundleId>.png   иконка, вынутая из бандла как есть (CgBI не трогаем)
files/                 только для мелких приложений, которые кладём к себе
catalog.tsv            генерируется tools/add_app.py в релее, руками не править
```

Заполненный под лимит Pages шард помечается в `relay.tsv` как `frozen`,
и заводится следующий.

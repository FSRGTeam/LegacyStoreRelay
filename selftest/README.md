# Канарейка Pages

Настоящий PNG, вынутый из бандла iOS — то есть в варианте **CgBI**, который
десктопные библиотеки не читают. Лежит здесь, чтобы в любой момент проверить,
что GitVerse Pages отдаёт бинарные файлы байт в байт, а не портит их
перекодировкой или подстановкой HTML-страницы.

    curl -s https://fsrgteam.gitverse.site/legacystorerelay/selftest/canary.png | sha256sum
    # должно совпасть с canary.sha256

Каталог и иконки раздаются тем же механизмом, поэтому если канарейка цела —
цел и весь каталог.
